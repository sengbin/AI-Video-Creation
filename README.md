# AI视频创作助手

面向 AI 视频创作流程的 Visual Studio Code 扩展。扩展提供九个创作 Prompt、AI 视频创作 Agent 和通用生成提示词 Skill。创意写作、图片灵感写作、小说重创作、剧本创作和拍摄脚本制作会直接生成最终作品；角色、场景、道具和特效任务生成供下游模型使用的提示词。

运行 Prompt 后，Copilot 会调用对应参数表单；表单提交内容用于组织本次生成结果。直接创作类任务输出作品内容，视觉资产类任务输出中英文提示词。生成质量受所用模型能力影响。

图片灵感写作可直接在参数表单中上传 PNG 或 JPEG 图片；小说原作仍需要作为 Copilot 聊天附件或消息内容提供。

扩展会将 `github.copilot.chat.imageUpload.enabled` 的默认值设为 `false`，以绕过图片附件远程下载问题。已有的用户级或工作区级设置优先；卸载扩展后，此默认值覆盖会自动移除。

## 开发

需要安装 Node.js 和 npm。

```powershell
npm install
npm run compile
npm test
```

在 VS Code 中打开本目录，按 `F5` 启动扩展开发宿主。运行 `npm test` 验证扩展和资源注册。

## 使用

1. 安装扩展并打开 Visual Studio Code。
2. 在 Copilot Chat 中选择任一扩展提供的视频创作 Prompt。创意写作、图片灵感写作、小说重创作、剧本创作和拍摄脚本制作直接生成作品；角色、场景、道具和特效生成供下游模型使用的提示词。
3. 允许对应的参数收集工具运行，在表单中填写任意字段或留空，然后选择“确定并继续”。
4. 如使用图片灵感写作，在参数表单顶部上传图片，也可以将鼠标移到图片区域后按 `Ctrl+V` 粘贴剪贴板图片；Copilot 会按要求生成对应体裁的完整作品。小说重创作、剧本创作和拍摄脚本制作所需的原作或创作素材可粘贴到同一聊天或作为附件提供。
5. 点击活动栏中的“AI视频创作助手”图标，可按提示词分类查看已保存的数据；每条记录都可以修改。

工具调用需要当前 VS Code Agent 和所选模型支持扩展工具调用。工具权限由 VS Code 管理，首次调用时可能需要批准。

扩展技能依赖 VS Code Agent Skills 支持；VS Code 1.108 首次提供该能力且当时需要启用 `chat.useAgentSkills`。建议使用较新的 VS Code 版本。
