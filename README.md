# AI视频创作助手

面向 AI 视频创作流程的 Visual Studio Code 扩展。扩展提供九个创作 Prompt 和 AI 视频创作 Agent。创意写作、图片灵感写作、小说重创作、剧本创作和拍摄脚本制作会直接生成最终作品；角色、场景、道具和特效任务生成供下游模型使用的提示词。

可以从任务分类创建并保存任务，再从任务行运行生成；也可以在 Copilot Chat 中直接运行扩展 Prompt，通过参数表单提交后继续生成。生成结果会保存到对应任务记录。直接创作类任务输出作品内容，视觉资产类任务输出中英文提示词；生成质量受所用模型能力影响。

图片灵感写作可直接在参数表单中上传 PNG 或 JPEG 图片；小说原作仍需要作为 Copilot 聊天附件或消息内容提供。

扩展会将 `github.copilot.chat.imageUpload.enabled` 的默认值设为 `false`，以绕过图片附件远程下载问题。已有的用户级或工作区级设置优先；卸载扩展后，此默认值覆盖会自动移除。

## 开发

需要安装 Node.js 和 npm。

```powershell
npm install
npm run compile
npm test
```

在 VS Code 中打开本目录，按 `F5` 启动扩展开发宿主。运行 `npm test` 验证扩展和资源注册。

## 使用

1. 安装扩展并打开 Visual Studio Code。
2. 点击活动栏中的“AI视频创作助手”，在“项目管理”中点击“创建”，填写项目名称并保存。
3. 按“内容创作”分组创建需要的创作任务，例如创意写作、图片灵感写作或小说重创作。图片灵感写作可上传或粘贴 PNG/JPEG 图片；小说原作需在 Copilot Chat 中提供。
4. 内容生成后，再按“视觉资产创作”分组创建角色、场景、道具或特效任务，生成后续创作所需的提示词。
5. 最后依次创建“剧本创作”和“拍摄脚本制作”任务：剧本任务选择所属项目及该项目中已生成内容的任务；拍摄脚本任务选择同一项目及已生成的剧本任务。

每个任务填写信息后点击“保存”，再从任务行点击“运行生成”。首次运行时在确认框点击“确认生成”；已有生成结果时按提示输入四位验证码，再点击“重新运行生成”。生成结果会保存到对应任务记录，点击任务名称可查看。

工具调用需要当前 VS Code Agent 和所选模型支持扩展工具调用。工具权限由 VS Code 管理，首次调用时可能需要批准。
