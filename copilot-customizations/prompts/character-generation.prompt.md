# 角色生成

## 使用范围

本 Prompt 用于生成人类、动物、怪物、丧尸等角色的参考图提示词，可直接交给图像生成工具使用。

开始生成角色内容前，必须调用一次 `ai-video-creation-tools_collect_character_parameters` 工具，等待用户在扩展表单中提交参数。不要把参数列表输出为聊天文本。

如果工具结果为 `status: cancelled`，停止生成并告知用户本次操作已取消。如果结果为 `status: submitted`，从 `parameters` 读取表单内容；空字段表示该项不需要收集，不得追问、猜测或补造空字段内容。仅依据已填写参数和其他已提供的视觉设定生成提示词；资料不足以描述某项时，省略该项或说明限制。

## 通用提示词规范

按图像生成提示词结构组织最终内容。当前交付物是可直接复制给下游图像生成模型的提示词，不是角色分析说明或图像本身；最终提示词使用一个代码块交付。

## 角色设定流程

1. 根据用户提供的角色资料或参考图确定角色类型和主体，只提取与角色可视化呈现有关的信息。
2. 整理用户确认的角色类型、角色外观和装束；外观描述可包含年龄、性别、身体结构、毛发或表面特征及辨识细节，不补写剧情身份、人物关系或性格经历。
3. 根据角色类型描述适用的身体结构和外观细节，例如人类的五官与服装、动物的毛发与体态、怪物的异形结构、丧尸的腐坏特征；不适用的属性不强行添加。
4. 结合用户填写的神态姿态、视角构图、画面风格、背景、画幅比例及补充要求组织画面描述。
5. 输出可直接交给图像生成工具使用的角色参考图提示词，清楚描述角色外观和画面要求。
6. 对照已确认的外观设定保持角色特征一致；按用户要求重写时只调整指定部分。

## 输出与生成质量要求

提示词应准确呈现用户确认的角色类型、外观、身体结构、辨识特征和适用的装束，并遵守神态姿态、构图、风格、背景及画幅要求；需要多个造型时，分别生成对应提示词并保持角色特征一致。

## 信息处理

空字段不追问、猜测或补造；依据已提供信息继续，无法完成的部分说明限制并跳过。用户明确表示某项不适用时按该答复处理，不扩展成其他设定。信息互相矛盾时指出冲突并询问采用哪一项。
