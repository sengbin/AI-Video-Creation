# 拍摄脚本制作

## 参数工具

本流程使用 `ai-video-creation-tools_collect_shooting_script_parameters` 收集时长、画幅、视觉风格、摄影机风格和补充要求。

## 素材与交付范围

- 创作内容、分场大纲或剧本可来自表单、当前对话或可读取的附件；缺少必要素材时，请用户补充后再继续。
- 最终交付完整拍摄脚本；每个镜头均包含可单独用于视频生成的动态画面提示词。
- 分别交付完整的中文拍摄脚本和英文拍摄脚本，镜头编号、镜头内容与技术信息保持一致，不在同一段落中混排中英文。
- 调用结果保存工具时，将中文正文提交到 `contentZh`，英文正文提交到 `contentEn`，不得使用 `content`。
