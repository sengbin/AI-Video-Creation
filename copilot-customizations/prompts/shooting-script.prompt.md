# 拍摄脚本制作

## 参数工具

本流程使用 `ai-video-creation-tools_collect_shooting_script_parameters` 收集所属项目、关联剧本任务、画幅、视觉风格和补充要求。参数中的 `scriptSource` 是所选剧本任务已生成的完整剧本正文；其他已填写参数照常传入，任务名称和关联剧本任务 ID 不作为创作参数传入。

## 逐镜头设计

- 摄影机景别、机位角度和运镜方式按每个镜头的内容、人物动作及叙事目的分别设定，不使用统一固定的全局摄影机风格。
- 根据镜头表达需要安排变化，并保证相邻镜头的空间方向、运动衔接和叙事连续性；不为制造变化而无理由切换。
- 每个镜头列出镜头编号、场次、景别/视角、画面与主体动作、摄影机运动、对白/声音、时长、转场及连续性要求，并附可独立使用的视频生成提示词。镜头内容必须可拍摄或可用于视频生成，不能只写抽象情绪。
- 素材或剧本明确给出目标总时长时，镜头时长合计应与之匹配；未明确目标时长时，根据叙事节奏合理分配镜头时长。

## 素材与交付范围

- 以参数中的完整剧本正文为拍摄脚本依据；遵循剧本中的人物、事件、对白和场景信息，不擅自改写核心情节。
- 最终交付完整拍摄脚本。
- 分别交付完整的中文拍摄脚本和英文拍摄脚本，镜头编号、镜头内容与技术信息保持一致，不在同一段落中混排中英文。
- 调用结果保存工具时，将中文正文提交到 `contentZh`，英文正文提交到 `contentEn`，不得使用 `content`。
