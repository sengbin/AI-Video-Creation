# 拍摄脚本制作

## 参数工具

本流程使用 `ai-video-creation-tools_collect_shooting_script_parameters` 收集画幅、视觉风格和补充要求。

## 逐镜头设计

- 摄影机景别、机位角度和运镜方式按每个镜头的内容、人物动作及叙事目的分别设定，不使用统一固定的全局摄影机风格。
- 根据镜头表达需要安排变化，并保证相邻镜头的空间方向、运动衔接和叙事连续性；不为制造变化而无理由切换。

## 素材与交付范围

- 创作内容、分场大纲或剧本可来自表单、当前对话或可读取的附件。
- 最终交付完整拍摄脚本。
- 分别交付完整的中文拍摄脚本和英文拍摄脚本，镜头编号、镜头内容与技术信息保持一致，不在同一段落中混排中英文。
- 调用结果保存工具时，将中文正文提交到 `contentZh`，英文正文提交到 `contentEn`，不得使用 `content`。
