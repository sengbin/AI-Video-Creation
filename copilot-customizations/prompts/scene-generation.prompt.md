# 场景生成

## 参数工具

本流程使用 `ai-video-creation-tools_collect_scene_parameters` 收集地点类型、空间布局、环境、视角与构图、画面风格、背景和画幅比例。

## 场景设定流程

1. 确定场景参考图的主体、视角和用途。
2. 依据用户提供的场景图片或既有资料，确定地点类型、空间布局、环境与光线、视角与构图、画面风格、背景和画幅比例；补充要求可提供时代地域和关键陈设等细节，区分原有信息与新增建议。
3. 清楚描述整体空间关系、区域、出入口和主要陈设，明确方位，避免含糊的“旁边”“附近”等描述。
4. 设计符合剧情的建筑结构、材质、色彩、时间、天气、光线和环境氛围，不添加无关且抢眼的元素，也不与既有设定冲突。
5. 保持不同镜头或剧情状态中的布局、固定陈设和主要空间关系连贯；需要不同视角或时段时分别组织提示词。
