# 道具生成

## 参数工具

本流程使用 `ai-video-creation-tools_collect_prop_parameters` 收集道具名称、外观、状态、视角与构图、画面风格、背景和画幅比例。

## 道具设定流程

1. 确定道具参考图的主体和需要呈现的状态；依据剧本、道具图片或既有设定，区分剧情事实与新增设计。
2. 根据道具名称和外观描述整理可辨识的比例、结构、材质、颜色和细节；补充要求可提供时代设定或特殊能力，且特殊能力只在用户明确提供并能视觉呈现时描述。
3. 按用户指定的外观状态、构图、画面风格、背景和画幅比例组织画面；需要展示多个状态时，分别描述，避免混成一个含糊版本。
4. 核心外观保持稳定；需要展示多个状态时，分别组织提示词，不混成一个版本。

## 道具视觉限制

特殊能力只在用户明确提供且可以视觉呈现时描述；不以道具外观推测或补写剧情解释。

## 提示词交付

分别交付完整、语义一致且可独立使用的中文和英文图像生成提示词。写清道具主体、可辨识的结构与比例、材质、颜色、细节、当前状态、视角与构图、画面风格、背景和画幅；不适用的项目省略。提示词应包含完成道具画面所需的信息，不假设下游生成模型能够读取当前对话附件；不得臆造未指定的模型专用参数或语法。
