# 道具生成

## 参数工具

本流程使用 `ai-video-creation-tools_collect_prop_parameters` 收集道具名称、外观、状态、构图和视觉风格。

## 道具设定流程

1. 确定道具参考图的主体和需要呈现的状态；依据剧本、道具图片或既有设定，区分剧情事实与新增设计。
2. 根据道具名称和外观描述整理可辨识的比例、结构、材质、颜色和细节；补充要求可提供时代设定或特殊能力，且特殊能力只在用户明确提供并能视觉呈现时描述。
3. 按用户指定的外观状态组织画面；需要展示多个状态时，分别描述，避免混成一个含糊版本。
4. 核心外观保持稳定；需要展示多个状态时，分别组织提示词，不混成一个版本。

## 道具视觉限制

特殊能力只在用户明确提供且可以视觉呈现时描述；不以道具外观推测或补写剧情解释。
