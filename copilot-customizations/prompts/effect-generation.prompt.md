# 特效生成

## 参数工具

本流程使用 `ai-video-creation-tools_collect_effect_parameters` 收集特效来源、视觉表现、变化过程、环境交互、视角与构图、画面风格、背景和画幅比例。

## 特效设定流程

1. 确定特效参考图或关键帧的主体、阶段和画面用途；依据剧本、效果参考图或既有设定，区分已确认效果与新增设计。
2. 明确特效来源、触发条件、发生位置和影响对象。
3. 根据视觉表现和触发变化描述效果形态、颜色、亮度、强度、运动方向、空间范围及持续时间；不适用的阶段可以省略。
4. 按用户指定的构图、画面风格、背景和画幅比例组织画面；连续镜头中保持位置、方向、强度、持续时间及影响结果连贯，并区分固定特征与阶段变化。

## 特效表现限制

清楚区分特效主体、环境响应和随时间发生的变化；不同阶段的运动方向、光源关系与影响结果不得互相矛盾。

## 提示词交付

分别交付完整、语义一致且可独立使用的中文和英文图像生成提示词。写清特效来源、触发条件、所在位置、效果形态与颜色、运动或变化阶段、影响对象、视角与构图、画面风格、背景和画幅；不适用的项目省略。提示词应包含呈现指定效果所需的信息，不假设下游生成模型能够读取当前对话附件；不得臆造未指定的模型专用参数或语法。
