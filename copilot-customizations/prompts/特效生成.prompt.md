# 特效生成

## 使用范围

本 Prompt 用于生成可直接交给图像生成工具使用的特效参考图或关键帧提示词。

开始生成特效内容前，必须调用一次 `ai-video-creation-tools_collect_effect_parameters` 工具，等待用户在扩展表单中提交参数。不要把参数列表输出为聊天文本。

如果工具结果为 `status: cancelled`，停止生成并告知用户本次操作已取消。如果结果为 `status: submitted`，从 `parameters` 读取表单内容；空字段表示该项不需要收集，不得追问、猜测或补造空字段内容。按已填写参数和其他已提供信息生成提示词；资料不足以描述某项时，省略该项或说明限制。

## 通用提示词规范

优先使用 `ai-video-prompt-design` Skill，按图像或视频生成提示词结构组织最终内容。当前交付物是可直接复制给下游生成模型的提示词，不是特效分析说明或已生成的图像/视频；最终提示词使用一个代码块交付。

## 特效设定流程

1. 确定特效参考图或关键帧的主体、阶段和画面用途；依据剧本、效果参考图或既有设定，区分已确认效果与新增设计。
2. 明确特效来源、触发条件、发生位置和影响对象。
3. 按时间顺序描述效果的开始、发展、峰值、衰减和结束；不适用的阶段可以省略。
4. 说明效果形态、颜色、亮度、强度、运动方向、空间范围、持续时间，以及对人物、道具和环境的交互与影响。
5. 输出特效参考图或关键帧提示词，区分主体效果、环境响应与镜头表现。
6. 生成连续镜头方案时，保持位置、方向、强度、持续时间及影响结果连贯，并明确保持不变和随时间变化的部分。

## 输出与质量要求

输出可直接用于图像生成的特效参考图或关键帧提示词，描述触发状态、位置范围、视觉形态、颜色亮度、运动方向及环境交互。明确区分“看见什么”和“效果如何变化”；提示词不得包含矛盾的运动方向、光源关系或效果阶段。

## 信息处理

空字段不追问、猜测或补造；依据已提供信息继续，无法完成的部分说明限制并跳过。剧本、参考图与用户确认内容不一致时，指出冲突并请求确认。
