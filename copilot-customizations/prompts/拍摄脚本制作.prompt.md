# 拍摄脚本制作

## 使用范围

本 Prompt 用于根据用户提供的故事、分场大纲或剧本，编写一份交给下游模型的拍摄脚本生成提示词。下游模型应将内容拆解成可执行的镜头，并为每个镜头生成可直接交给视频生成模型使用的图生视频提示词。

开始整理拍摄要求前，必须调用一次 `ai-video-creation-tools_collect_shooting_script_parameters` 工具，等待用户提交表单。不要把参数列表输出为聊天文本。

如果工具结果为 `status: cancelled`，停止本次操作并告知用户已取消。如果结果为 `status: submitted`，从 `parameters` 读取内容；空字段表示该项不需要收集，不得追问、猜测或补造。故事、分场大纲或剧本可以来自表单或当前对话；必需素材缺失时，说明缺失并请用户补充。

## 通用提示词规范

优先使用 `ai-video-prompt-design` Skill，重点遵循视频生成提示词结构。当前交付物是下游模型的拍摄脚本生成提示词，不是已经拆好的完整拍摄脚本。提示词必须说明：每个镜头都要附一段独立、可复制给视频生成模型的动态画面提示词；不得假设下游模型能读取当前 Copilot 对话附件。

## 拍摄提示词设计流程

1. 整理故事或剧本中的场次、人物、地点、关键动作、对白、情绪变化、时长和必须保留的内容；不改变已确认的剧情事实。
2. 按场景和动作节拍拆镜，确保镜头能够连续呈现剧情因果，不遗漏关键动作、信息揭示或情绪转折。
3. 为每个镜头规定必要信息：镜头编号、所属场次、预计时长、景别与视角、画面主体和动作、摄影机运动、构图与光线、对白/声音、转场及连续性要求。
4. 为每个镜头编写独立的图生视频提示词，描述起始画面、主体动作及其时间顺序、镜头变化和结束状态；明确人物、服装、道具、空间、光线等跨镜头锚点。
5. 汇总镜头时长并核对目标总时长；检查镜头运动、角色位置、道具状态、视线方向和场景布局是否连贯。
6. 按用户指定的画幅、风格、制作条件和模型要求组织交付，不臆造未指定的视频模型专用语法或参数。

## 下游拍摄脚本交付结构

提示词要求下游模型按场次分组输出镜头表。每个镜头至少包含：镜头编号、场次、时长、景别/机位、画面与动作、摄影机运动、对白/声音、转场/连续性要求、可复制的视频生成提示词。没有对白或声音的镜头可标为无，不得为了填表添加无关内容。总时长应与镜头时长合计相符。

## 输出要求

输出一个标注为“可直接复制的生成提示词”的代码块。提示词中包含源剧本或故事素材、镜头拆解规则、镜头表字段、每镜头图生视频提示词要求、连续性锚点、总时长核对方式和禁止事项。若下游模型必须读取原始材料，在代码块中放入清晰的素材占位符，供用户粘贴；代码块外仅说明必要的待确认事项。
