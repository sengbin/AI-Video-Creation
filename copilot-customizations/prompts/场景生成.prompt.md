# 场景生成

## 使用范围

本 Prompt 用于生成可直接交给图像生成工具使用的场景参考图提示词。

开始生成场景内容前，必须调用一次 `ai-video-creation-tools_collect_scene_parameters` 工具，等待用户在扩展表单中提交参数。不要把参数列表输出为聊天文本。

如果工具结果为 `status: cancelled`，停止生成并告知用户本次操作已取消。如果结果为 `status: submitted`，从 `parameters` 读取表单内容；空字段表示该项不需要收集，不得追问、猜测或补造空字段内容。按已填写参数和其他已提供信息生成提示词；资料不足以描述某项时，省略该项或说明限制。

## 通用提示词规范

按图像生成提示词结构组织最终内容。当前交付物是可直接复制给下游图像生成模型的提示词，不是场景分析说明或图像本身；最终提示词使用一个代码块交付。

## 场景设定流程

1. 确定场景参考图的主体、视角和用途。
2. 依据用户提供的场景图片或既有资料，确定空间类型、时代地域、时间地点及已确认的视觉条件；区分原有信息与新增建议。
3. 清楚描述整体空间关系、区域、出入口和主要陈设，明确方位，避免含糊的“旁边”“附近”等描述。
4. 设计符合剧情的建筑结构、材质、色彩、时间、天气、光线和环境氛围，不添加无关且抢眼的元素，也不与既有设定冲突。
5. 输出场景参考图提示词，明确镜头视角、构图重点和必须保留的空间特征。
6. 生成时保持不同镜头或剧情状态中的布局、固定陈设、光线、天气和主要空间关系连贯；必要变化应有剧情依据。

## 输出与质量要求

输出可直接用于图像生成的场景参考图提示词，包含必要的空间布局、建筑结构、关键陈设、时间天气、光线氛围、镜头视角和画面风格。需要不同视角或时段时，分别生成提示词，不混为一张图。

## 信息处理

空字段不追问、猜测或补造；依据已提供信息继续，无法完成的部分说明限制并跳过。剧本、参考图与用户新指示冲突时，指出冲突并以用户最新确认内容为准。
